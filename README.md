# WallPainter — рисуем на стене

Приложение для Android TV-приставки (с проектором): на стене чёрный «холст», а рисуют на нём с телефона через обычный браузер (подходит iPhone, ничего ставить не нужно). Компьютер не нужен — веб-сервер встроен прямо в приложение на приставке.

## Как пользоваться

1. Установите [`tvapp/WallPaint.apk`](tvapp/WallPaint.apk) на приставку и запустите «Рисуем на стене».
2. На стене появится QR-код — отсканируйте его камерой телефона (телефон в той же Wi-Fi-сети). Или откройте адрес вида `http://<IP приставки>:8765/`.
3. Рисуйте. Как только кто-то подключился, стена становится полностью чёрной. Кнопка **OK** на пульте снова показывает QR-код на 15 секунд.

### Возможности
- Кисть, маркер, ластик, лазерная указка (след гаснет сам), текст, линия, стрелка, прямоугольник, овал (с заливкой и без), заливка области.
- Палитра из 13 цветов + любой свой, толщина (готовые размеры и ползунок).
- Отмена / повтор своих действий, очистка стены, сохранение картинки на телефон.
- Фото с телефона: выбрать, подвинуть пальцем, растянуть двумя пальцами, нажать «Готово» и рисовать поверх.
- Несколько телефонов сразу: кисть у одного, остальные видят рисунок и могут нажать «Попросить кисть». Владелец отдаёт её или оставляет себе; без ответа за 10 секунд кисть переходит сама.

## Устройство проекта

```
tvapp/
  AndroidManifest.xml
  src/com/wallpaint/tv/
    MainActivity.java   — полноэкранный WebView, запускает сервер, кнопка OK = показать QR
    WallServer.java     — HTTP + WebSocket сервер (порт 8765), состояние рисунка, логика «кисти»
  assets/
    phone.html          — интерфейс рисования для телефона
    tv.html             — экран стены (слои, QR-код)
    common.js           — общий рендерер: объекты, заливка, указка, переподключение
    qr.js               — генератор QR-кодов без зависимостей
  res/drawable/         — иконка и баннер для лаунчера Android TV
  build.ps1             — сборка APK без Gradle
  debug.keystore        — отладочный ключ подписи (пароль android)
  WallPaint.apk         — собранное приложение
```

Рисунок — это список объектов (штрих, фигура, заливка, текст, фото) в координатах 0..1. Телефон шлёт их по WebSocket, сервер хранит список и рассылает всем, стена и телефоны рисуют одинаково.

## Сборка

Нужны Android SDK (build-tools 36.0.0, platforms/android-36) и JDK 17.

```powershell
$env:ANDROID_HOME = 'D:\Android\sdk'   # по умолчанию
.\tvapp\build.ps1
```

## Установка по Wi-Fi (ADB)

```powershell
adb connect <IP приставки>:5555
adb install -r tvapp\WallPaint.apk
adb shell am start -n com.wallpaint.tv/.MainActivity
```

Подпись тем же `debug.keystore` позволяет обновлять приложение поверх старой версии без удаления.

### Быстрая правка интерфейса
HTML/JS лежат в `tvapp/assets` и попадают в APK. После правки — пересобрать и переустановить (команды выше).
